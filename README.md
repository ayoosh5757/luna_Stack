# Luna Stack 🌙 | Basic Navigation Task

This is my first assignment for the Mobile Applications course. The project demonstrates a fundamental understanding of **Stack Navigation** in Flutter using a "Magic & Moonlight" aesthetic.

## 📝 Assignment Requirements
- [x] Create a Home Screen.
- [x] Create a Details Screen.
- [x] Implement forward navigation using `Navigator.push()`.
- [x] Implement backward navigation using `Navigator.pop()`.
- [x] Add interactive buttons on each screen.

---

## 🎨 Design & Theme
The app features a **Soft Pink & Lavender** theme, providing a cute and magical user experience.

- **Primary Color:** Pink (Representing the Luna magic).
- **Background:** Soft Pastel Pink (For a clean, feminine look).

## 🚀 How it Works
1. **Push:** Clicking the magic button pushes the `LunaDetailScreen` onto the top of the stack.
2. **Pop:** Clicking "Go Back" pops the current screen, revealing the `LunaHomeScreen` underneath.
